# Apuntes-Ciencia-de-Datos
Los apuntes para la evaluación del curso de competencias
Repositorio con apuntes, ejercicios y proyectos del curso.

## Estructura

| Carpeta / Archivo | Descripción |
|---|---|
| `Perceptron/` | Notas sobre el perceptrón |
| `Redes densas/` | Material sobre redes neuronales densas |
| `Redesdensas_segundocorte/` | Contenido del segundo corte |
| `Parcial_CNN/` | Parcial de clasificacion de huevos |
| `Prendas/` | El ejercicio de streamlit |
| `taller/` | Talleres de clase |
| `imagenes/` | Las imagenes de algunos cuadernos y la del parcial |
| `Prueba.py` | Script de prueba |

## Requisitos

- Python 3.x
- Node.js (para las dependencias de `package.json`)


## Notas

Los archivos pueden estar un poco desordenados por fuera de las carpetas debido a pruebas sueltas de software independiente, pero las carpetas estan organizadas segun los temas de las clases.
